# Social Media API

## Цель проекта

Разработка серверной части социальной сети, в которой пользователи могут
взаимодействовать друг с другом, добавлять друзей, публиковать записи и
общаться.

## Центральный процесс дружбы

1.  Пользователь отправляет другому пользователю заявку в друзья.
2.  Отправитель становится подписчиком получателя.
3.  Получатель принимает заявку.
4.  Система создаёт дружескую связь между пользователями.
5.  Оба пользователя становятся подписчиками друг друга.
6.  Система отправляет уведомления участникам процесса.

## Локальное окружение

Для работы приложения используется PostgreSQL 17, запускаемый в Docker.

Перед первым запуском создайте файл `.env` на основе `.env.example`.

**Linux / macOS:**

``` bash
cp .env.example .env
```

**Windows (PowerShell):**

``` powershell
Copy-Item .env.example .env
```

### Запуск PostgreSQL

Для запуска PostgreSQL дождитесь прохождения проверки готовности
контейнера:

``` bash
docker compose up -d --wait
```

Проверить состояние контейнера можно командой:

``` bash
docker compose ps
```

### Запуск тестов

**Linux / macOS:**

``` bash
./mvnw test
```

**Windows (PowerShell):**

``` powershell
.\mvnw.cmd test
```

### Запуск приложения

**Linux / macOS:**

``` bash
./mvnw spring-boot:run
```

**Windows (PowerShell):**

``` powershell
.\mvnw.cmd spring-boot:run
```

После запуска приложение будет доступно по адресу
<http://localhost:8080>.

### Проверка API

Для проверки доступности сервиса выполните команду:

``` bash
curl http://localhost:8080
```

Ожидаемый ответ:

``` json
{
  "status": "ok",
  "service": "social-media-api"
}
```

### Остановка окружения

Для остановки и удаления контейнеров PostgreSQL выполните:

``` bash
docker compose down
```

Данные PostgreSQL сохраняются в именованном Docker volume и остаются
доступными при следующем запуске.
